# Submission documents

Put the four required PDFs here, renamed with the team name (replace `TeamName`). The blank templates are in the organisers' Google Drive folder linked from the [submission template](https://github.com/michaelzhngg/SDC_Hackathon_Submission_Template).

| File | What it is | Status |
|---|---|---|
| `SDC2026_TeamName_Preliminary.pdf` | Preliminary submission form (deadline 25 October 2026) | Answers drafted in [drafts/Preliminary.md](drafts/Preliminary.md) |
| `SDC2026_TeamName_TechDeclaration.pdf` | Technology declaration | Answers drafted in [drafts/TechDeclaration.md](drafts/TechDeclaration.md) |
| `SDC2026_TeamName_Replit_POU.pdf` | Replit proof of use | Screenshots: the Repl, the Deployments page with the live URL, the Database and Secrets tabs (hide values) |
| `SDC2026_TeamName_Runpod_POU.pdf` | RunPod proof of use | Screenshots: the Serverless endpoint, its Requests tab, and the output of `python runpod/smoke_test.py` |

The drafts are written within each question's word limit. Fill every `[bracket]`, read each answer, then copy it into the official PDF template. Do not put API keys or other secrets in any document.
